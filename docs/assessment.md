## Как повторить проверку

```console
uv sync --locked
uv run ruff check .
uv run ruff format --check .
uv run python -m unittest discover -s tests -v
uv run python -m tools.record_demo
uv build
```

## Уточнения для защиты

- Стартовые 10 000 USD согласованы с заказчиком вместо пустого портфеля.
- На момент этой сверки 47 автоматических тестов проверяют сценарии без сети.
- Демо использует фиксированные ответы HTTP и это указано в начале записи.
  Его вывод получен реальным исполнением CLI, клиентов, хранилища и сделок.
- Реальный CoinGecko ранее проверен запросом с получением трёх курсов.
  Для проверки ExchangeRate-API на защите нужен собственный ключ; реальные
  запросы с этим ключом не выполнены. Автоматические тесты покрывают его контракт.
- JSON-файлы создаются при работе приложения, поэтому в репозитории нет
  пользовательских паролей, кошельков или устаревающего снимка котировок.
- Обновления двух JSON-файлов не являются одной транзакцией. Восстановление
  снимка из истории покрыто тестом, межпроцессная блокировка Parser реализована;
  для пользовательских данных рассчитан один процесс Core.
- В пункте 1.2 рубрики упоминаются «цели», но в присланных этапах Makefile
  не требовался. Используются команды uv и GitHub Actions, перечисленные выше.
